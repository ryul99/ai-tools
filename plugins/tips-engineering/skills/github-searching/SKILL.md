# GitHub Searching Guidelines

- Treat an issue or pull request description as initial context, not the current conclusion.
- Check the current state of the item, including whether it is open, closed, or merged and the reason for its current state.
- Read the latest substantive comments, reviews, and timeline events for corrections, decisions, regressions, and follow-up work.
- Keep in mind that an issue or pull request may contain incorrect information. Many large open-source projects have a history of inaccurate or incomplete issue and pull request descriptions, comments, and reviews.
