# Tips Engineering

`tips-engineering` is an extensible collection of lazily loaded tips for
software engineering workflows.

## Installation

### Codex

```sh
codex plugin add tips-engineering@ryul99-ai-tools
```

### Claude Code

```sh
claude plugin install tips-engineering@ryul99-ai-tools
```

## Included skills

- `github-searching`: Tips for effectively searching GitHub issues and pull requests.
