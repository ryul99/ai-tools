# Tips Engineering

`tips-engineering` provides guidance for software engineering workflows.

## Installation

### Codex

```sh
codex plugin add tips-engineering@ryul99-ai-tools
```

### Claude Code

```sh
claude plugin install tips-engineering@ryul99-ai-tools
```

## Included skills

- `github-searching`: Tips for effectively searching GitHub issues and pull requests.
- `ui-principles`: Principles for designing and reviewing any user interface, from applications to HTML reports and slide decks.
